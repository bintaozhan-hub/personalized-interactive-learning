# Book Wiki

由 `book-reading` skill 产出的深度阅读记录。

## 原始文件

书籍 PDF 等原始文件存放在 `raw/book_raw/` 目录中，由用户自行放入。

## 产出文件

每本书一个独立子文件夹，包含：
- `《书名》.md` — 书籍元信息（基本信息 + 阅读目的 + 阅读蓝图 + 核心收获 + 跨书关联）
- `第X部分-核心问题.md` — 每个部分的深度阅读笔记（核心观点 + 关键概念 + 苏格拉底诘问记录 + 应用场景）

## 索引文件

- `index.md` — 所有已读/在读书籍的索引列表
- `log.md` — 阅读活动日志（开始阅读、完成部分、完成全书）

由 AI 自动维护，无需手动编辑。
