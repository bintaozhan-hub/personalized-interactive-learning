# User Wiki — 用户个人档案

由 `life-interviewer` skill 创建和维护。这是整个学习系统的基础——其他 skill 会读取这里的档案来定制化内容。

---

## 七维度结构

| 维度 | 存什么 | 示例 |
|------|--------|------|
| 01_身份与角色 | 职业、社会身份、家庭角色 | 产品经理、自由职业者、父亲 |
| 02_价值观与信念 | 判断标准、核心信念 | 重视自主权、偏好长期主义 |
| 03_底层思维模式 | 认知框架、决策习惯 | 实用主义推理、系统思维 |
| 04_技能与特长 | 硬技能、软技能、爱好 | Python、公开演讲、摄影 |
| 05_人际关系网络 | 重要的人、关系性质 | 导师、合作伙伴、家人 |
| 06_人生重大轨迹 | 转折点、关键经历 | 换城市、创业、重大失败与收获 |
| 07_当下状态与近期事件 | 近期事件、当前目标 | 正在找新工作、学一门新技能 |

---

## 使用方式

1. 触发 `life-interviewer` skill："我想聊聊我的经历"
2. AI 会按时间线回溯（童年 → 学生 → 大学 → 工作 → 当下）
3. 聊完后说"帮我沉淀一下"，AI 会自动归档到对应维度
4. 也可以直接把简历、日记等放入 `raw/user_raw/`，然后触发沉淀

---

## 文件命名规则

- 每个维度的总览文件命名为该维度名，如 `身份与角色.md`
- 单个人物文件以人名命名，如 `哥哥.md`
- 单个事件文件以 `YYYY_事件描述.md` 命名，如 `2021_大三危机与接纳不确定性.md`
