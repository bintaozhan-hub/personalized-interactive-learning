## 问题设计指南

### 三个层次

| 层次 | 考查什么 | 题目特征 | 示例 |
|------|---------|---------|------|
| 理解检验 | 是否理解了核心概念 | "用自己的话解释"、"举个例子" | "用你自己的话解释一下什么是规模效应？能举一个你身边行业的例子吗？" |
| 应用能力 | 能否用概念分析实际问题 | 给一个场景，要求用本节框架分析 | "假如你要判断一家连锁咖啡品牌是否值得投资，你会用本节讲的哪种分析框架？具体分析哪几个维度？" |
| 批判思考 | 能否看到概念的局限 | 要求指出局限、反例或边界条件 | "本节分析了新能源汽车的三种技术路线。在这三种路线之外，你觉得还有哪种可能性没有被讨论到？为什么？" |

### 问题设计原则

- **开放而非选择题**：用户用自己的话回答时，才能真正暴露理解程度
- **具体而非抽象**：问"分析一下某个东西"不如问"假如你是投资人，你会看哪三个指标？为什么？"
- **渐进深度**：三个问题由浅入深，先确认理解了，再检验应用和批判能力
- **关联 MISSION**：问题应与用户的研究目的相关联，让用户觉得"这个问题对我有用"
- **关联用户背景**：如用户生活/工作与该领域相关，用用户自己的场景提问——"你作为XX行业的从业者，这套框架如果应用到你的工作中会怎样？"比通用问题更能触发深度思考
- **可操作**：用户不需要查阅额外资料就能回答

## 正文编写指南

### 结构原则：金字塔

```
          ┌─────────────┐
          │  核心结论    │  ← 先说结论
          └──────┬──────┘
     ┌───────────┼───────────┐
┌────┴────┐ ┌────┴────┐ ┌────┴────┐
│  论点A   │ │  论点B   │ │  论点C   │  ← 再展开论据
└────┬────┘ └────┬────┘ └────┬────┘
  ┌──┴──┐    ┌──┴──┐    ┌──┴──┐
  │论据  │    │论据  │    │论据  │  ← 最后给数据/案例
  └─────┘    └─────┘    └─────┘
```

**不是**：先堆数据再总结 → 读者在中途就迷失了
**而是**：先给结论 → 展开论点 → 用数据支撑 → 让读者随时知道"为什么在讲这个"

### 语言原则

```
✅ 好的写法：
"新能源汽车行业的核心驱动力是'政策 + 技术 + 需求'三重叠加。
政策方面，中国的双积分政策和欧洲的禁燃时间表直接拉动了供给端；
技术方面，电池成本过去十年下降了近 90%([T2] BNEF 2024)；
需求方面，消费者对电动车的接受度从 2019 年的 30% 上升到 2024 年的 68%([T2] 麦肯锡 2024)。"

❌ 差的写法：
"新能源汽车行业发展迅速。政策支持力度大。技术进步明显。消费者越来越接受。"
```

**原则：**
- ✅ 用具体代替模糊（"电池成本下降 90%" 而非 "技术进步明显"）
- ✅ 每个数据有出处（[T2] BNEF 2024）
- ✅ 解释数据意义（"直接拉动了供给端" 而非给你一个数字自己理解）
- ✅ 用类比降低认知门槛（"就像智能手机取代功能手机，靠的不是价格而是体验"）
- ❌ 不要堆砌术语（每引入一个新术语，立刻解释）
- ❌ 不要写博士论文式的长段（每段 3-5 句，讲一个点）

### 类比使用指南

**类比的目的**：用已知解释未知，降低认知负担。

**好的类比：**
- 只抓住最核心的相似性（不要试图全方位类比）
- 使用用户熟悉的领域（不确定时优先用日常生活中的事物）
- 明确类比的边界（"当然，这个类比不完全精确，因为..."）

**示例：**
```
"平台的网络效应就像一个派对——人越多，派对越有价值，越多人想来。
但注意这个类比的局限：派对到达一定人数后体验会下降（太挤），
而数字化平台通常不存在这个问题。"
```

## 课后问题示例

### 好的问题示例

**理解检验：**
> "用你自己的话解释一下什么是'飞轮效应'。如果你要给一个完全不懂商业的朋友讲这个概念，你会怎么讲？"

✅ 好在哪里：要求用户重新表达，而不是复述。能暴露真正的理解程度。

**应用能力：**
> "我们本节讲了电商平台的三种盈利模式（佣金、广告、会员）。现在假设你要创业做一个二手奢侈品交易平台，你会选择哪种盈利模式？为什么？你认为最大的挑战是什么？"

✅ 好在哪里：给了一个具体但假设的场景，要求用户综合运用多种知识做判断。

**批判思考：**
> "本节我们得出'规模效应是电商行业最核心的竞争壁垒'这一结论。但你也知道 Temu 和 Shein 以极低价格快速抢占了市场份额——这是否对'规模效应是壁垒'这一结论构成了挑战？你如何看待？"

✅ 好在哪里：用一个真实的"反例"挑战用户刚学到的结论，检验深度理解。

### 差的问题示例

**选择题（❌）：**
> "飞轮效应属于以下哪种效应？A.网络效应 B.规模效应 C.协同效应 D.以上皆是"

❌ 差在哪里：选择题无法暴露理解程度；用户可以猜对。

**过于宽泛（❌）：**
> "你对这节课的内容有什么想法？"

❌ 差在哪里：太开放，用户可能不知道从何说起。

**照搬讲义（❌）：**
> "请复述本节讲的三层产业链结构。"

❌ 差在哪里：考的是记忆力，不是理解力。

## 编号与命名规则

### 编号
- 从 0001 开始，每节递增
- 编号不可重复，不可跳号
- 创建新课前，先扫描 `lessons/` 目录找最高编号

### Slug 命名
- 使用中文简写或英文 kebab-case
- 反映本节核心主题
- 示例：`0001-行业概览.md`、`0002-产业链结构.md`、`0003-竞争格局.md`

## 篇幅控制

| 场景 | 建议字数 | 说明 |
|------|---------|------|
| 入门介绍类 | 1500-2500 字 | 重在建立图景，不追求细节密度 |
| 深度分析类 | 2500-4000 字 | 需要足够的论据和数据支撑 |
| 比较/批判类 | 2000-3000 字 | 重在逻辑和视角，不需要堆数据 |
| 数据密集型 | 2000-3500 字 | 数据多用表格展示，减少文字描述 |

**原则上**：宁可分成两节短课，也不塞成一节长课。用户的注意力是稀缺资源。
